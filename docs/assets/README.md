# docs/assets

README や配布物で使うブランド画像の置き場。

| ファイル | 実寸 | 形 | 用途 |
|---|---|---|---|
| `logo.png` | 1672 × 941 | 横長バナー | **README の先頭**(`width="520"` で表示)。横に長いので、正方形の枠へ入れると余白が目立つ |
| `logo_small.png` | 600 × 600 | 正方形 | **アイコン用途**。GitHub の Social preview / ファビコン / アプリアイコンなど、正方形の枠に収める場所 |

⚠️ **用途で使い分けること。** 横長バナーを正方形の枠に入れると左右が切れるか上下に余白が入り、
正方形をバナー位置に置くと文字が読めない大きさになる。

📌 `logo_small.png` は音ゲーテンプレート側(`music-game-client-template`)のタイトル画面でも
同じ画像を使っている。**片方だけ差し替えると見た目が食い違う**ので、ブランドを変えるときは
両方を更新すること。
