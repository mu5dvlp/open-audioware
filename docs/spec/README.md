## 凡例

- **【確定】** — 合意済み。勝手に変更しない。変更が必要と判断したら必ず確認を取ること。
- **【仮】** — 妥当な既定値として設定したもの。実装は進めてよいが、後から変わりうる前提で
  「1箇所を書き換えれば済む」構造(設定構造体 / 定数)にしておくこと。
- **【未定】** — 未決。実装フェーズで到達する前に確認を取ること。

本書で**テンプレート仕様「話題名」**と呼ぶものは、クライアントテンプレート
(`music-game-client-template`)の仕様書(初期構築後は `docs/spec/` / `docs/adr/` に置かれる本体仕様)を指す。
特定のファイル名には依存しない。
